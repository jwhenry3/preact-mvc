PREACTMVC

Angular's architecture.
JSX's ergonomics.

Modules, dependency injection, and decorators around class-based views on Preact — with signal reactivity and worker-rendered islands. Build the app Angular would structure with the components React would write.

Read the docs Live demos

Modules & DI

@Module, hierarchical injectors, inject() in field initializers — Angular's scoping model, no decorators-era baggage.

Class views

@Component + View: inject once at mount, render is plain code — no hooks, no deps arrays, no stale closures.

MVC organization

@Controller classes own interaction state; declaration scope decides who shares the instance.

Signals

signal/computed/effect with scope-bound disposal — fine-grained updates, no manual unsubscribe.

Worker islands

The same view classes render inside Web Workers, streamed to the shell DOM over an op protocol. Real multithreaded UI.

Enterprise-ready

Tailwind + shadcn patterns, TanStack Query via DI, zod forms, ECharts — see the live enterprise example.
